Single program

Open the program (on Windows, double-click it): a wizard asks which apps should get Noul and copies it to a fixed folder in your user profile. On macOS and Linux, extract the .tar.gz and run ./noul in a terminal.

  • Windows (x64)
  • macOS (Apple Silicon)
  • Linux (x64)

Windows: if "Windows protected your PC" appears, click More info → Run anyway. macOS: the first time, go to System Settings → Privacy & Security → Open Anyway. The files are not digitally signed yet. SHA256SUMS only detects corrupted downloads; to confirm that a file was built by this repository, run gh attestation verify <file> --repo ernaneDomingues/noul-search-agent.
