LatticeFormer: Sequence Transduction with Gated Lattice Attention
Ana Ribeiro Kenji Sato
Abstract
We introduce LatticeFormer, an encoder-decoder built only from gated lattice attention for trans-
lation. On the WMT14 English-
to-German task it reaches 29.1 BLEU, and on English-to-French a single model reaches
42.3 BLEU after training for 2.5 days on eight GPUs.
1 Introduction
Recurrent encoders process tokens one at a time, which limits parallelism when the sequence
length n is much larger than the batch. Gated lattice attention relates every pair of positions
in a constant number of sequential steps.

2 Background
Prior attention models combine attention with recurrence. We remove recurrence entirely and
rely on lattice attention with learned gates.
3 Model Architecture
3.1 Gated Lattice Attention
Given queries Q, keys K and values V, the attention is
GLA(Q, K, V) = softmax(QK^T / sqrt(d_k)) V (1)
The scaling factor is justified by assuming that query and key entries are uncorrelated and
have unit spread.
3.2 Position Encoding
We add fixed sinusoidal encodings to the token embeddings so that the model can use
order information.

4 Why Lattice Attention
Table 1: How the cost of one layer and its serial steps grow for each layer kind we compare, given a
length n and a width d.
Layer Type Complexity Sequential Operations
Lattice attention O(n^2 d) O(1)
Recurrent O(n d^2) O(n)
Lattice attention costs grow quadratically with the sequence length, so very long inputs remain
expensive.
5 Training
5.1 Data
We train on the standard WMT14 English-German data with byte-pair encoding.
5.2 Optimizer
We use the Adam optimizer with beta1 = 0.9, beta2 = 0.97 and epsilon = 1e-9. The learning rate
follows an inverse square-root schedule with warmup_steps = 3000.
5.3 Regularization
We apply dropout with rate Pdrop = 0.15 to every sub-layer, and label smoothing of value 0.1
during training. Each batch holds about 24000 source tokens.
