## Noul Search (scientific evidence across all disciplines)

For scientific, academic, medical, engineering, CS/AI, or economics research questions ("does X improve/outperform Y?", literature reviews, technical deep dives, peer review, code scaffolding, academic writing, BibTeX sanitization, rebuttal, or pre-submission desk-reject audits) use the `noul` MCP tools (`search_papers`, `get_paper`, `clarify_search_scope`, `detect_paper_domain`, `get_paper_references`, `scan_paper_artifacts`, `compare_papers`, `get_thematic_insights`, `generate_research_hypotheses`, `extract_benchmark_tables`, `estimate_hardware_specs`, `verify_paper_claims`, `extract_paper_math`, `analyze_ablation_tables`, `extract_prompts_and_decoding`, `detect_failure_modes`, `diff_arxiv_versions`, `review_paper`, `scaffold_implementation`, `recommend_citations`, `synthesize_related_work`, `generate_manuscript_blueprint`, `audit_manuscript_draft`, `sanitize_bibtex`, `parse_and_draft_rebuttal`, `audit_submission_readiness`, `get_fulltext`, `query_fulltexts`, `related_papers`, `citation_graph`, `download_papers`, `save_research_dossier`, `export_papers`, `export_obsidian_notes`, `evidence_meter`, `configure_noul`) or, without MCP, `python3 __NOUL_DIR__/noul_cli.py search "<query>"`.
Read and follow `__NOUL_DIR__/skills/noul-search/SKILL.md` for the workflow and answer format (Evidence Meter / Noul Meter, cited synthesis, study table, evidence quality, paper list, and follow-up PDF downloads / related paper discovery). Cite only retrieved papers.
